# Функция памяти чатов в Bext AI

Теперь приложение полностью поддерживает сохранение истории чатов между сессиями!

## Что реализовано:

### 1. **Автоматическое сохранение чатов**
- Все сообщения автоматически сохраняются в localStorage браузера
- Каждый чат получает уникальный ID и название (первые 50 символов первого вопроса)
- Хранится информация:
  - Дата создания чата
  - Количество сообщений
  - Дата последнего обновления

### 2. **Загрузка последнего чата при открытии**
- При открытии приложения автоматически загружается последний активный чат
- Вы видите свои предыдущие сообщения и ответы ИИ
- История чата полностью восстанавливается

### 3. **Панель истории**
- Раздел **"История"** показывает все сохраненные чаты
- Можно искать чаты по названию
- Можно удалить любой чат
- Нажатие на чат загружает его полностью

### 4. **Экспорт и импорт истории**
В разделе **"Баптаулар"** (Настройки) добавлены кнопки:

#### Экспорт (Сохранение)
- Кнопка **"Экспорт қылу"** скачивает JSON файл со всей историей
- Содержит все чаты со всеми сообщениями
- Удобно для резервной копии или переноса на другой компьютер

#### Импорт (Восстановление)
- Кнопка **"Импорт қылу"** позволяет загрузить ранее сохраненный JSON файл
- Загруженные чаты добавляются к существующим (не заменяют)
- Защита от дублей - чаты с одинаковыми ID не добавляются

## Техническая информация:

**Где хранятся данные:**
- Все данные хранятся в localStorage браузера
- Ключи: `bext_chat_${chatId}` для сообщений, `bext_history` для списка чатов
- Последний активный чат: `bext_last_chat_id`

**Формат экспорта:**
```json
{
  "version": "1.0",
  "exportDate": "2026-05-01T10:30:00Z",
  "totalChats": 5,
  "chats": [
    {
      "id": "1234567890",
      "title": "Математика формулалары...",
      "timestamp": "2026-05-01T10:00:00Z",
      "messageCount": 10,
      "lastUpdated": "2026-05-01T10:30:00Z",
      "messages": [...]
    }
  ]
}
```

## Как использовать:

### Загрузка предыдущего чата:
1. Откройте приложение
2. Нажмите на **"История"** в боковом меню
3. Выберите нужный чат

### Сохранение истории:
1. Перейдите в **"Баптаулар"** (Настройки)
2. Найдите раздел "Тарихты сақтау және қалпына келтіру"
3. Нажмите **"Экспорт қылу"** - скачается JSON файл

### Восстановление истории:
1. Перейдите в **"Баптаулар"** (Настройки)
2. Нажмите **"Импорт қылу"**
3. Выберите сохраненный JSON файл
4. Чаты автоматически добавятся к существующим

## Особенности:

✅ Все данные остаются в браузере (приватность гарантирована)
✅ Автоматическое сохранение без дополнительных действий
✅ Поддержка импорта/экспорта для переноса между устройствами
✅ Неограниченное количество сохраненных чатов
✅ Защита от потери данных через экспорт

## Ограничения localStorage:

- Обычный лимит: 5-10 МБ на одного сайта
- При достижении лимита браузер не сможет сохранить новые данные
- Если необходимо больше - используйте экспорт для архивирования старых чатов
